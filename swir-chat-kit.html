SWIR OS // CHAT SERVER KIT

Build your chat server

SWIR Chat on GitHub Pages is only the client. Download the API, upload it to your own PHP hosting, connect it to MySQL/MariaDB and paste the generated API URL + Public Chat Key back into SWIR Chat.

SWIR Chat APISelf-installing PHP backend. Creates the chat tables and generates API keys.

Installation guideShort setup guide for cPanel / PHP hosting / MySQL or MariaDB.
CH
Open SWIR ChatAfter installing the backend, return to Chat and paste your generated connection details.
1
Download the API

Save swir-chat-api.php from this screen.

2
Create an empty database

In cPanel or your hosting panel create MySQL/MariaDB database + user.

3
Upload the PHP file

Put it on a PHP 8+ hosting account and open it in your browser.

4
Run installer

Enter database data and set Allowed Origin to https://swir.github.io.

5
Connect SWIR Chat

Paste the generated API URL and Public Chat Key into the chat setup screen.

The Public Chat Key is intentionally a client-side instance key, not an administrator password. Keep the generated Admin Key private.
